# 山海轮回 · 三印归途（Release 1）

独立 Three.js 单人动作 RPG。**这是三个有限地区、可通关并自愿轮回的短篇战役，不是无限世界，也不是商业美术终版。** 原游戏、原场景与减面实验页没有改动。

## 启动

从仓库根目录启动静态服务器（需要保持相邻共享资产目录）：

```sh
python3 -m http.server 8769 --bind 127.0.0.1
```

打开 `http://127.0.0.1:8769/progress-site/game/reincarnation/`。不支持直接双击 `file://`；没有构建步骤、服务端、登录、付费或联网 AI。

## 完整流程

新旅程 → 渡口右侧招募灵伴 → 左侧神龛补药 → 探索/开箱/击败巡游灵兽 → E 拾取装备 → 行囊装备 → 中央祭坛花灵钱升级 → 向北挑战守卫 → 北侧光门进入下一境 → 击败三个不同机制守卫 → 通关页 → 继续探索或自愿下一世。

- 青岚渡：草木、暖雨/薄雾；潮汐守卫瞄准玩家位置，1.25 秒蓄力圆形爆发。
- 赤砂关：风蚀暖色地貌、沙雾/晴；守卫以自身为中心 4.5 单位震荡，1.6 秒预警、较长恢复。
- 霜月宫：冷色连廊与雪雾；49 房间端口约束布局，守卫 0.9 秒追猎圆环，交替快慢冷却。
- 每境 5 普通敌人、1 守卫、2 宝箱；总量有限，无刷怪/重复奖励。敌人追击、蓄力、攻击、脱战返回。
- 每境入口有恢复神龛；未击败本境守卫不能前往下一境；南侧光门返回上一境并恢复其离开点。
- 生命归零进入死亡页；本境渡口复苏保留进度/掉落/装备/冷却，不自动开始轮回。
- 通关后轮回重置装备、灵钱、等级、宠物、技能和任务，只保留每世 +5 HP / +1 攻击传承，最多 10 层。

## 操作

| 操作 | 桌面 | 触屏 |
|---|---|---|
| 移动 | WASD / 方向键，或点地面 | 左摇杆 / 点地面 |
| 普攻 | J（可按住） | 攻击（可按住） |
| 三术法 | 1 / 2 / 3 | 破浪 / 飞霜 / 镇山 |
| 闪避 | 空格，移动中沿方向闪避 | 闪避 + 摇杆 |
| 药剂 | H | 药剂 |
| 拾取、开箱、招募、祭坛、传送 | E | 交互 |
| 背包 / 暂停 | I / Esc，或顶栏 | 顶栏按钮 |

摇杆与攻击独立 pointerId，允许同时按住；丢失焦点/触点取消/转向/菜单清除输入。菜单、加载与死亡停止规则时钟和攻击。竖屏和横屏均可玩，不强制横屏。红圈是将爆发的地面范围，移出范围或利用 0.7 秒闪避无敌。攻击/技能不消耗蓝量，其代价为按技能身份保存的冷却；药剂数量有限，神龛补至至少 4。

## 生成和数值合同

细节见仓库 `full-game/implementation/ALGORITHMS.md`。所有持久随机源由 `version:seed:stable-ID` 派生：地区顺序不会改变后续地区。装备在敌人/箱子的固定 ID 上生成，不能刷新洗词缀。新游戏用本机 crypto 随机种子，轮回派生新种子并排除已有种子。

WFC 不是标签：16 个四向端口 tile，最小域观察、对向端口相等传播，49 次坍缩/最多 4 次尝试，预留纵向主干和横向连接；最后 flood fill 要求 49 房间连通。矛盾/断路时走独立确定性、端口合法的保底布局。野外为带种子梯度 Perlin 双频地形，主路独立压平。固定三境战役连接图，不声称每次更换宏观任务拓扑。

## 存档和隐私

仅使用 `shanhai.reincarnation.release1` 与 `.backup`，从不清除 `shanhai.adventure.v1` 或旧备份。存档包含完整地区敌人状态、死亡/已发奖/掉落/开箱、任务、HP/经验/装备/宠物、技能冷却、死亡与复苏标记、世界时钟/天气/季节、返回点。没有离线时间推进。

写入前保留上一份合法备份，主档无效可读备份；配额/禁用存储时显示错误，暂停页可导出非秘密 JSON。导入限制 300KB、版本、数值边界、世界结构、种子装备、重复 ID、任务一致性；不执行导入代码。不要把本机保存当云同步。浏览器清理网站数据仍会丢失存档，请导出。

## 追加成长系统（兼容已发布 v1）

- 顶栏「任务」或 L 打开手记：三境各有踏入、两箱、五怪、守卫目标，另有灵伴一阶目标；共13项，每项每世仅领一次。旧档已完成目标可领取，不强制重开。
- 渡口中央祭坛保留技能/灵伴培养，新增药剂（12钱/瓶，最多99）和灵砂（18钱/2砂，最多999）兑换；神龛原有免费补至4瓶仍保留。
- 行囊展示换装前攻击/护甲/生命差值。仅未装备物品可二次确认分解，得到稀有度+1灵砂；不返还强化消耗，不能重复分解。
- 强化确定成功，最多+3，三次分别花20/35/50钱和1/2/3砂；武器每阶+3攻，护甲+2甲，饰品+8血。单件攻/甲/血仍分别不超过60/35/90，人物护甲不超过60%。基础装备原对象不改，强化独立按装备ID保存。
- `version`、`generator`、seed流均保持1；新增可选 `progression` 保存领取记录、灵砂、强化和分解记录。缺少该字段的旧档补零默认，保留其他所有状态；非法新增值拒绝导入，不静默清档。离线JSON并非防作弊服务器，不能阻止玩家自行重写整个合法存档。
- 启动标题立即显示，不再等待可选合集；合集请求5秒超时后回退现有本地资产，进入场景前等待这个有界结果，防止迟到修改模型映射。模型首次响应等待最多60秒，收到数据后按45秒无进展检测，并设3分钟总期限；显示真实已接收数据量。失败显示重试并保持加载门控；模块未加载时HTML仍有启动文字和刷新按钮。
- 验证脚本及合成旧档位于 `full-game/continuation/`；`old-schema.synthetic.json` 使用修改前规则快照生成，不含用户私人存档。原测试文件保持只读，包装器仅重定向截图/证据输出到 continuation。

## 模型与集成

- 默认主角是获认可原版 `../assets/licensed-hero/hero.glb`，不是减面实验主角。原片段只是静态姿势；位移、转向和挥击是整模变换，不宣称存在行走/战斗骨骼动画。
- 角色只加载现成 GLB；模型失败显示具体 URL 和重试按钮，绝不生成几何人形代替。
- `app.mjs` 导出的 `MODEL_CONFIG` 是集成入口。启动读取 `../assets/cc0-collection/manifest.json`，支持 `{mobs,bosses,pets,items,props}` 数组，每项 `{id,name,url}`；URL 以本页面为基准，可以指向 `../asset-library/assets/id.glb`。怪物、Boss、宠物类别接入角色选择；items/props 目录预留，目前拾取物以光环表示，景物沿用已存在场景套件。
- 合集缺失不阻止玩法，明确显示“现有灵狐/灵猫变体”，不把同模型放大当新物种。备用灵狐使用已有减面灵狐资产，主角始终原版；来源和许可沿用仓库原资产元数据。
- 场景采用已有亭、柱、过渡岩石 GLB，程序生成地形/道路/围墙/树冠属于环境，不属于自制人物。

## 性能边界与局限

显式区域加载页；场景离开时释放拥有的几何、材质、纹理及克隆骨骼，模型基础资源作为有界共享缓存保留。最多 6 活跃 AI，96 天气粒子，20 个实例化树冠，像素比不超过 1.5。没有后台无限刷怪。

当前是简洁战役玩法，不是精细动作游戏：没有角色原生跑动动画、音效、任务配音；怪物使用简化直线追击/返回，未实现复杂导航网格绕障，环境装饰不参与精确碰撞。玩家在第三境必须遵守房间端口通路；灵伴为跟随式战斗助手，无独立生命条。季节改变地表色调、日光和地域天气，不模拟真实气象。大规模世界、无缝区块流式、Worker 生成和实体设备性能不是本次已完成项。

## 实测与调试

测试和证据在 `full-game/implementation/`：

```sh
node full-game/implementation/core.test.mjs
node full-game/implementation/browser-normal.test.mjs
node full-game/implementation/browser-touch.test.mjs
node full-game/implementation/browser-fixtures.test.mjs
```

浏览器测试使用仓库已有 Playwright 与 Chromium，需要上面的静态服务器。普通页面 `window.__reincarnation` 只返回状态深拷贝，不提供写入口。只有显式 `?test=1` 才提供 `window.__test.setup(name)` 边界测试夹具；报告分别标记正常玩家操作与夹具。正常桌面和触屏完整通关测试不调用夹具、不改玩家状态，不以直接设置胜利代替战斗。

Chromium 触控模拟不等于实体手机 QQ / Safari 验收；公网部署与复测结果以发布记录为准。
